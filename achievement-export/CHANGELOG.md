# 更新日志

每次发布前新增对应版本的二级标题，例如 `## [0.2.0] - YYYY-MM-DD`。
推送标签 `v0.2.0` 后，release 工作流提取该版本内容，通过 `gh` 发布 GitHub Release。
预发布标签（例如 `v0.2.0-beta.1`）对应同名版本章节，并标记为预发布。

## [0.1.0] - 2026-11-14

### 新增

- Windows 桌面导出器，支持导出鸣潮账号 UID 和成就进度。
- 本机网页交接及 JSON 文件导入，按 UID 保存账号，同 UID 覆盖更新。
- v3 精简进度格式，静态文本、分类与奖励由网页配置补齐。

### 优化

- 移除运行时配置查询模块，保留未知成就 ID 的原始进度。
- 使用 HttpListener 替换 Kestrel，移除 ASP.NET Core 运行时依赖。
- 标准版精简框架语言资源并内置 .NET，Lite 版使用系统安装的 .NET 10 Desktop Runtime（x64）。两版均为单文件。
- 保留双快照稳定性校验及交接来源、密钥和有效期检查。
